Frontend vs. Backend Tasks
Comprehensive Breakdown of Pending Issues
🔐 1. Authentication & Session Management
Frontend Tasks:
Interceptors / Route Guards: Implement request/response interceptors to
automatically catch 401 Unauthorized responses and trigger clean redirects.
Token Cleanup: Ensure all local state (Redux, Context, localStorage, or cookies) is
fully wiped upon manual logout or token expiration.
Silent Refresh (if implemented): Handle token refresh triggers in the background
before they expire.
Backend Tasks:
Token Generation & Validation: Review JWT expiration times, signature validation
keys, and cookie security flags (e.g., HttpOnly, Secure).
Security Middleware: Ensure backend routes consistently throw appropriate 401 or 
403 HTTP status codes instead of redirecting or hanging on invalid tokens.
📊 2. Dashboard Issues
Frontend Tasks:
Route Mapping: Resolve the routing 404 error by checking the Next.js file-system
routing structure (e.g., check if the directory structure matching /dashboard/
insights/overview or similar has the correct page.tsx file).
Visual Integrations: Update layout components, graphs, and tables to correctly display
aggregated data for Attendance Analytics and Expense Audit.
Backend Tasks:
Aggregation Endpoints: Verify and optimize the database queries/endpoints
responsible for aggregating analytics (e.g., overall attendance percentages, total
expense approvals). Ensure they do not timeout or return empty data.

⏰ 3. Attendance Management
Frontend Tasks:
Working Hour Formatter: Format raw backend-provided minutes into a readable
hours/minutes format (e.g., 6h 15m).
Filter UI: Build interface filters (dropdowns, calendars/date pickers, search input) and
wire them to API query parameters.
Employee Analytics Charts: Integrate a charting library (like Recharts or Chart.js) to
display individual attendance patterns visually.
Backend Tasks:
Status Calculation Logic: Update the checkout database trigger or API controller to
calculate the total duration. Implement the business rule: 
Less than 4 hours → Absent
4 to 7 hours → Half Day
More than 7 hours → Present
Filtered API Listing: Update the attendance list API to accept query variables
(userId, status, startDate, endDate) and perform corresponding DB filtering.
🔔 4. Notification Module
Frontend Tasks:
Socket / SSE Listeners: Integrate WebSockets (socket.io-client) or Server-Sent
Events (SSE) inside React/Next.js to listen for real-time notification events.
Toast UI: Design active notification alert popups/toasts that render dynamically when
events occur.
Backend Tasks:
Event Broadcasting: Set up the WebSocket/SSE server to handle user connections,
rooms/rooms grouping, and broadcast notification events.
Simulation Endpoint: Create a secure developer test endpoint to trigger simulated
notification broadcasts.
Reliable Outbox: Build notification queues so offline users receive pending notifications
when they reconnect.

🌴 5. Leave Management
Frontend Tasks:
"View Report" Button / UI: Add interactive triggers to the UI. Implement a report view
or details modal.
Backend Tasks:
Consolidated API: Build a reporting endpoint that queries and returns a summary of
the employee's history (e.g., accumulated leaves, approved/pending balance, and policy
limits).
🗣️ 6. Employee Feedback
Frontend Tasks:
Payload Stripping: Ensure the feedback form does not submit any identifying
identifiers (such as userId, authorName, or authorization tokens if the endpoint
requires anonymity).
Backend Tasks:
Anonymous Schema & Routes: Allow the feedback endpoint to accept unauthorized/
unauthenticated posts, or design the feedback database schema without any relation/
foreign keys back to the User table to guarantee true anonymity.
🎨 7. UI/UX Improvements
Frontend Tasks (100% Client-Side):
Skeleton Loader Components: Create reusable skeleton components matching your
layout structures.
React Suspense & Transitions: Wrap heavy components in <Suspense>
boundaries. Optimize layouts to avoid cumulative layout shifts (CLS).
Backend Tasks:
None (this is purely visual client-side performance).

👥 8. Team Hierarchy
Frontend Tasks:
Hierarchy Component: Build a recursive Tree component with state variables allowing
node expansion and collapse.
Backend Tasks:
Nested Tree Payload: Write recursive database queries (e.g., using SQL Common
Table Expressions (CTEs)) that construct and return hierarchical manager-employee
trees based on managerId relations.
📑 9. Reports & Export
Frontend Tasks:
CSV Downloader: Take the data payload and construct a client-side downloadable
CSV link, or serve the download trigger pointing directly to the backend stream.
Backend Tasks:
Data Export Endpoint: Build a fast SQL query to fetch raw tabular data and stream it
back as text/csv to support large datasets safely.
💰 10. Payroll Policy Automation
Frontend Tasks:
Deduction Visibility: Build panels on both employee and admin screens to display
policy violations, late streak counts, and calculated payroll deductions.
Backend Tasks (Core Automation):
Cron / Scheduler: Write a nightly or weekly worker to track late arrivals.
Streak Calculation: Implement consecutive late arrival calculation logic (updating a 
lateStreakCount or evaluating the calendar).
Rule Engine Deduction: Code the payroll calculation formulas to automatically check
for 3 consecutive late days and apply the 2.5-day salary deduction before generating
the final pay slip.
